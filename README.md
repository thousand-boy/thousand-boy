# Portfolio

## 01. 書類確認漏れ防止Webアプリ

**医療現場で実際に経験した書類確認漏れを、Java / Spring Bootを使って仕組みで防ぐWebアプリを制作しています。**

以前の職場では、月30件前後の書類確認漏れが発生していました。

1ヶ月分の発生内容を分析した結果、

- 漏れが特定の書類に集中している
- 確認担当者が明確でない
- 複数人で確認することで責任の所在が曖昧になっている

という問題が分かりました。

そこで、確認担当者と確認手順を整理した結果、  
**月30件前後あった確認漏れを7〜8件程度まで削減しました。**

この経験から、**人の注意力だけに頼るのではなく、システムで確認状況を管理できるようにしたい**と考え、Webアプリとして再現しています。

### 実装予定

- 書類情報の登録・編集・削除
- 確認状況の管理
- 未確認書類の一覧表示
- 担当者管理
- ステータス更新
- データベース保存
- REST API
- 入力値チェック
- エラー処理
- 単体テスト

### 使用技術

- Java
- Spring Boot
- SQL
- Database
- REST API
- Git / GitHub
- JUnit

### この制作で重視していること

**完成させることよりも、課題を整理し、設計し、実装し、テストして改善する一連の流れを理解することを重視しています。**

READMEには、

- なぜこの機能が必要なのか
- なぜその設計にしたのか
- どこでつまずいたのか
- どのように調査・解決したのか

まで記録します。

> ※患者情報などの個人情報は使用せず、すべて架空データで制作します。
